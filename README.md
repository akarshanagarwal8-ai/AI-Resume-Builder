# AI Resume Builder

A professional AI-powered resume builder web application.

## Features

- AI Resume Summary
- Live Resume Preview
- Multiple Templates
- Resume Strength Meter
- Dark Mode
- PDF Download
- Profile Photo Upload
- Responsive UI

## Technologies Used

- HTML
- CSS
- JavaScript
- Tailwind CSS
- html2pdf.js
